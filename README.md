Student details
1. Basic information
Student ID — generated by the system

Full name

Date of birth / age

Gender — if genuinely needed

Profile photo — optional

2. Academic information
School/college name

Class/grade

Board — CBSE, ICSE, State Board, etc.

Subjects they want tuition for

Current academic level

Preferred language of instruction

3. Contact information
Student's email address

Student's phone number, where appropriate

Parent/guardian name

Parent/guardian phone number

Parent/guardian email

For younger students, it is generally useful to make the parent/guardian the primary contact rather than collecting unnecessary direct contact details from the child.

4. Tuition preferences
Preferred class days

Preferred time

Individual or group tuition

Online class preference

Learning goals

Topics where the student needs help

5. Login information
For example:

Student ID / Email
Password

Store passwords securely using hashing, never as plain text.

6. Payment information
If your platform handles payments, you might store:

Course/enrollment selected

Payment status

Invoice/receipt number

Subscription/fee plan

Avoid storing card numbers or other sensitive payment details yourself when a trusted payment gateway can handle them.
